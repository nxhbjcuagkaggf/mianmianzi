# 〔mianmianzi〕关键文献

「[开源人文学者](https://github.com/ah-collective/hub)」的成员仓库。成员作为公共文献本身的实践。仓库包含本人阅读史上的关键文献，作为个人历史相对稳定的参照系，用以测量不同时间段同一个人的智识变化。git 的提交时间为每一次回答打上时间标记。

## 仓库名词

- **关键文献**：对你有过关键影响的几份文本。广义文本包括书、短篇、影片、专辑、网页，具有不断回返的母题价值。出现在条目的 `cite:` 部分。
- **条目**：即一次重读（对关键文献的一次重新诠释）。条目时间由 git 的提交时间决定。
- **心跳**：`pulse.md` 里无条目的月份一行。最小动作是确认本月度读法「无变化」。

## 心跳机制

- **本月存在文件变动**：个人创建条目或添加文献即为心跳，`pulse.md` 无需改动。
- **本月不存在文件变动**：需手动在 `pulse.md` 最下面**追加一行** `2026-10 无变化`（心跳）。无退出与加入机制，无心跳则不计入本月邮件通信；心跳恢复即恢复通信。

## 操作流程

全程在浏览器里完成，无需前置知识。手机浏览器同理。

### 建仓（首次）

1. **注册**（5 min）：打开 github.com，右上角 Sign up，用邮箱注册。用户名将来会出现在你仓库的网址里，建议用笔名或你不介意公开的名字。
2. **首次聊天**：和编目人一起从你的阅读史里说出三份个人智识的「关键文献」。仓库由编目人当场用模板在社群 org 下建好，仓名用你的笔名，每份文献的首条记忆写入。
3. **转移**：把注册的用户名告诉编目人。编目人把仓库**转移**到你的账号下，你会收到一封邮件，点 **Accept** 即可（一天内有效；转移前你名下不能有同名仓库）。

转移之后仓库所有权归你，包括删除权、退出权。旧地址会自动跳转到新地址。此后的每一条都由你自己提交，git 的提交时间戳具备实时含义。

如特殊情况不希望使用单独 GitHub 账号，仓库将留在本 org 下、你加为协作者。README 中将加上注释「本仓为代管，本人可随时要求转移或删除」。

### 添加条目

1. 打开你的仓库，点 **Add file** → **Create new file**
2. 文件名一栏填**路径**：`key/作品/2026-09-15.md`
   - 斜杠会自动变成文件夹
   - 日期用今天
   - 作品写短题名，**同一份文献的短题名每次保持一致**，脚本靠它把你的这一条和上一条对上
3. 顶部三行元数据，之后回答两个问题（问题原样照抄，每次不变；首次阅读只答「这一轮」）：
   ```
   ---
   cite: 普鲁斯特（Proust）《重现的时光》（Time Regained），《追忆似水年华》第七卷，1927
   where: 北京大学图书馆
   edition: 译林出版社 1991，徐和瑾、周国强译
   ---

   **上一轮阅读如何看待这个文本？**

   （回答）

   **这一轮阅读如何看待这个文本？**

   （回答）
   ```
4. 右上角绿色 **Commit changes…**。
